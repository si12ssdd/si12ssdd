### 🎨 AI Text-to-Image Generator Platform
<img src="https://img.shields.io/badge/Status-Live-39FF14?style=flat-square"/> <sub>Jul 2025 – Aug 2025 · Full Stack Developer</sub>

Full-stack MERN SaaS integrated with the **Clipdrop AI API** — handles multipart form-data and streams binary → base64 for real-time rendering.

- 💳 Dual payment gateways (**Razorpay & Stripe**) with server-side signature verification & idempotency checks to prevent forgery/double-crediting
- 🔐 Secure **JWT auth** with bcrypt hashing across 8 core REST endpoints (auth, credits, payments, generation)
- ⚛️ Responsive React UI with global state via **Context API**
- ⚙️ Automated **CI/CD** deployment via GitHub → Vercel

`React` `Node.js` `MongoDB` `JWT` `Razorpay` `Stripe` `Clipdrop AI`

**[🔗 Live Demo](https://text-to-image-frontend-sigma.vercel.app/)** · **[💻 Source](https://github.com/si12ssdd/AI-text-to-image-generator)**
